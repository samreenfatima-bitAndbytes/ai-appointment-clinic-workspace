# AI Appointment static demo — local setup

Vite + React static build for Vercel. No Django, calendar OAuth, or LLM keys.

## Run locally

```bash
cd local-projects/AI-Appointment-static
npm install
npm run dev
```

Open http://localhost:2100

## Demo logins

| Role     | Email                      | Password     |
|----------|----------------------------|--------------|
| Business | `owner@clinic.example`     | `DemoPass1!` |
| Admin    | `admin@appointment.example`| `DemoPass1!` |

## Vercel

- Root: this folder
- Build: `npm run build`
- Output: `dist`
